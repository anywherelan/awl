# Security Policy

## Supported versions

Only the latest release gets security fixes. Please update before reporting.

## Reporting a vulnerability

Please [**report it privately**](https://github.com/anywherelan/awl/security/advisories/new)
and **do not open a public issue**. We will reply in the advisory, and once a
fix is released, the advisory is published with credit to you, unless you ask
otherwise.

A weakness that cannot be exploited right away, or is in code that is not
released yet, can be discussed openly in an [issue](https://github.com/anywherelan/awl/issues/new).
